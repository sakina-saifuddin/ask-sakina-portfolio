# Sakina Saifuddin — Portfolio

Next.js portfolio for Sakina Saifuddin, focused on software engineering, data, BI, automation, machine learning, healthcare data, and project evidence.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Main pages

- `/` — portfolio home
- `/projects` — project archive
- `/projects/[slug]` — case studies
- `/resume` — embedded resume
- `/certificates` — certificates
- `/appreciation` — appreciation and recommendations

## Notes

- No OpenAI API key or LLM billing is required. **Ask My Resume** uses fixed, verified recruiter questions and answers.
- Project screenshots and recognition images are stored locally under `public/`.
- The browser icon uses the portfolio profile photo.
